# Trace data location

The full per-step / per-planning traces are kept on the data disk (they are
tens of MB and regenerated by the commands in `../TRACE_AUDIT.md`):

- Seeded (reproducible) run:
  `$HJEPA_HOME/ckpts/ant/ant_hjepa_l3/seed42/eval_ant_l3_trace_w1_seeded/trace/`
- Unseeded replay (gate evidence):
  `$HJEPA_HOME/ckpts/ant/ant_hjepa_l3/seed42/eval_ant_l3_trace_w1/trace/`

Each directory contains `meta.json`, `steps.jsonl`, `planning.jsonl`,
`tasks/task_XXX.json`, `trace_done.json` and `analysis/{summary.json,figures/}`.

Schema (one JSON object per line):

- `steps.jsonl`: `t, env, task, xy, goal_xy, qpos, qvel, action, success,
  terminated, truncated`
- `planning.jsonl`: `level, call_idx, steps_taken, horizon, num_samples,
  n_iters, wall_clock, goal_* , pred_* , actions, cost_batches, tasks`

Latent fields are bucket-mean summaries; they are not decoded to XY.
